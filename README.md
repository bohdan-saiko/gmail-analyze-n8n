# AI Assistant для фільтрації Gmail та сповіщень у Telegram

Цей воркфлоу для **n8n** автоматично перевіряє вашу пошту Gmail на наявність непрочитаних листів, аналізує їхній вміст за допомогою ШІ (Llama 3.3 на Groq), відсіює спам і надсилає стислий звіт (summary) у Telegram, якщо лист дійсно важливий.

## Як це працює
1. **Gmail Trigger** — щохвилини перевіряє пошту на наявність нових листів із фільтром `is:unread`.
2. **AI Agent + Groq (Llama-3.3-70b)** — виступає в ролі особистого секретаря. Аналізує відправника, тему, контекст і повертає строго структурований JSON.
3. **JavaScript Code** — парсить відповідь від ШІ.
4. **IF Node** — перевіряє прапорець `is_important`. Якщо лист неважливий (спам, розсилки) — ланцюг зупиняється.
5. **Telegram Node** — надсилає гарно відформатовану основну суть листа у ваш чат.

## Інструкція зі встановлення

1. Скопіюйте весь вміст файлу `workflow.json` з цього репозиторію.
2. Відкрийте свій локальний або хмарний n8n, створіть новий порожній воркфлоу.
3. Натисніть комбінацію клавіш **`Ctrl + V`** (або у правому верхньому кутку оберіть `...` -> *Import from File*).

## Що потрібно налаштувати (Credentials)
Воркфлоу не містить моїх персональних доступів, тому вам потрібно підставити власні:

* **Gmail account** — підключіть ваш Google акаунт (через OAuth2).
* **Groq account** — вставте ваш API-ключ від Groq (модель `llama-3.3-70b-versatile`).
* **Telegram** — підключіть вашого бота через токен від `@BotFather` та вкажіть ваш персональний `chatId` у налаштуваннях фінального блоку.

## Кастомізація промпту
Ви можете змінити критерії "важливості" листів. Для цього відкрийте блок **AI Agent** та відредагуйте текст у полі `Text` під ваші потреби (наприклад, додайте моніторинг листів від банку, університету чи конкретних сервісів).
